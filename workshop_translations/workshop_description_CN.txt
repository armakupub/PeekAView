[h1]扩展你的视野[/h1]

Project Zomboid 把许多你的角色其实看得到的东西藏在墙壁、树木和上层楼之后。PeekAView 扩展了三个渲染通道，让你的屏幕跟上角色的眼睛：

[list]
[*][b]墙壁切除[/b]：墙壁在更远的距离被切除，让转角和门口在你接近时更早显露出后方的内容。
[*][b]树木淡化[/b]：驾驶时，车辆周围的树木会变为半透明，让你更早看见危险。
[*][b]楼梯视图[/b]：攀爬楼梯时上层楼面会被渲染，让你在到达之前就看到楼上的情况。僵尸只在你正要进入的那个房间中显露。
[/list]

与原版相同的规则：无 X 光透视，无透明墙壁，无敌人轮廓。你角色的视线仍然决定什么是可见的。

每项功能在 选项 → Mod → Peek a View 下都有自己的「启用」开关。[b]F8[/b] 在游戏内切换整个 Mod（可重新绑定）。

从 Build 42.20 起，PZ 自带了步行时的树木淡化。在我看来它已经够用了，所以 PeekAView 的树木淡化现在只负责驾驶场景。如果 TIS 重做了他们的版本，或者我自己玩正式版时发现还有改进的余地，我会再回来处理。

[h1]常见问题[/h1]

[b]「修复 B42 墙体消失错误」这个选项具体做什么？[/b]
原版 B42 会让玩家自建结构旁的上层楼墙壁消失，从某些视角看会留下墙体空洞。该选项（默认关闭）会抑制这种情况。代价：贴在原版墙边的玩家自建平台在外立面上会显得更明显，所以只在你确实看到空洞时才开启它。

[b]我在 ZombieBuddy 的提示中拒绝了 PeekAView。能撤销吗？[/b]
编辑 [noparse]%USERPROFILE%\.zombie_buddy\mod_approvals.json[/noparse]：在 [noparse]"id": "PeekAView"[/noparse] 代码块中，把 [noparse]"decision": false[/noparse] 改为 [noparse]true[/noparse]（或者删除该代码块以便重新被询问）。然后重启 PZ。
